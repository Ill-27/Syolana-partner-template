# Partner Studio API — serverless skeleton

Это подготовленный серверный шлюз для production Partner Studio.

Он не активируется автоматически и не содержит секретов.

## Что умеет

- POST /session — вход по партнёрскому ключу;
- GET /posts — опубликованные посты и VK-черновики;
- POST /posts — публикация;
- PUT /posts/:id — редактирование;
- DELETE /posts/:id — удаление;
- POST /media — загрузка изображения до 8 МБ.

## Переменные окружения

- PARTNER_ID
- PARTNER_ACCESS_KEY_HASH — SHA-256 партнёрского ключа;
- SESSION_SECRET — длинная случайная строка;
- GITHUB_REPO — owner/repo конкретного партнёра;
- GITHUB_TOKEN — fine-grained credential только на этот repo;
- ALLOWED_ORIGIN — точный HTTPS origin Studio.

Секреты вводятся только в панели serverless-провайдера, не в GitHub и не в чат.

## Перед production

Нужно добавить:

- серверный rate limiting;
- полноценный журнал административных действий;
- автоматическое удаление/инвалидацию сессий при отключении партнёра;
- при необходимости YDB/другую российскую базу для аутентификации и журнала;
- проверку CORS/CSRF под выбранный API Gateway;
- GitHub App вместо PAT, когда партнёров станет много;
- антивирус/дополнительную проверку файлов при необходимости.

## Россия

Production endpoint и первичную базу аутентификации следует размещать с учётом требований РФ к персональным данным. Этот код — техническая заготовка; размещение и юридические роли фиксируются перед коммерческим запуском.
