# Подключение нового партнёра

## 1. Репозиторий

Для каждого партнёра создаётся отдельный репозиторий из Syolana Partner Template.

Рекомендуемое имя:

`syolana-<project-slug>`

Репозиторий принадлежит самому партнёру или передаётся ему сразу после настройки.

## 2. Хостинг

Базовые варианты:

- GitHub Pages — самый простой старт;
- Cloudflare Pages — удобно для собственного домена и дальнейшего edge-функционала.

Партнёр использует собственный аккаунт хостинга.

## 3. Домен

Домен покупает и контролирует партнёр. Syolana может помочь с подключением DNS, но не должна владеть доменом вместо партнёра.

## 4. Настройка

Заполнить `partner.json`:

- id;
- название;
- описание;
- публичное имя владельца;
- ссылки;
- категории.

## 5. Публикации

Каждый пост хранится отдельным JSON в `posts/`.

После изменения GitHub Actions автоматически:

1. проверяет структуру;
2. собирает `feed.json`;
3. публикует сайт.

## 6. Что уже поставляется централизованно

- актуальные стили Syolana;
- фирменные шрифты;
- баннер Syolana;
- темы и режим созерцания;
- звуки тем;
- общий музыкальный плеер и текущая библиотека песен;
- обновления центрального `partner-core.js`.

Новый дизайн и новые темы не копируются вручную в каждый сайт: партнёрский loader получает их из центрального Syolana Core при следующем открытии страницы.

## 7. Следующие этапы

- редактор публикаций на самом сайте партнёра;
- серверная очередь модерации;
- production-лицензия вместо демонстрационного JSON;
- уведомления о публикациях, требующих проверки;
- подключаемые книги/читалка для авторов, которым этот модуль нужен.
