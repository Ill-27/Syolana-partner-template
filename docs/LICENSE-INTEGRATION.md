# Лицензия Syolana

## Цель

Премиальный слой Syolana должен подключаться только для активных партнёров, не забирая у них сайт и контент.

## Планируемая проверка

Сайт отправляет на entitlement endpoint:

- partnerId;
- hostname;
- версию Syolana Core.

Ответ содержит только минимально необходимое:

- active: true/false;
- доступные функции;
- короткий срок действия ответа;
- версию Core / asset manifest.

## При окончании подписки

Остаются:

- домен партнёра;
- хостинг партнёра;
- его тексты;
- его изображения;
- базовая оболочка сайта.

Перестают подключаться только премиальные компоненты Syolana.

## Безопасность

Нельзя считать браузер абсолютной защитой от копирования. Всё, что уже было передано клиенту, теоретически можно сохранить.

Поэтому защита строится из нескольких уровней:

- короткоживущие entitlement;
- проверка домена;
- премиальные ассеты не хранятся в репозитории партнёра;
- условия лицензии запрещают обход ограничений;
- серверные секреты хранятся только у Syolana.


## Полное удаление следов интеграции

Окончательное отключение не должно оставлять видимый бренд Syolana на сайте партнёра.

Пока лицензия просто неактивна, `platform-loader.js` не загружает центральный слой вообще. Пользователь видит только независимую оболочку партнёра.

Для постоянного удаления интеграции запускается GitHub Actions workflow **Detach optional platform layer**. Он:

- удаляет `integration.json`;
- удаляет `platform-loader.js`;
- убирает тег загрузчика из `index.html`;
- оставляет `partner.json`, публикации, медиа и самостоятельный дизайн сайта;
- после коммита автоматически запускает обычный деплой standalone-сайта.
